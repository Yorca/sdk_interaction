    <div id="step0">
      <h2>Prerequisites</h2>
      <ul style="list-style-type: none;">
        <li>
          Make sure that your Android application meets the following requirements before proceeding.
          <div class="alert alert-primary">
            <ul>
              <li>
                Android 4.2.2 (Jelly Bean, API 17) and higher. MRAID ads require API 19 and higher.<br>
                <strong>Older Android versions may work, but are not officially supported.</strong>
              </li>
              <li>
                Google Play Services will adhere to the users ad tracking preferences. For more information, please see
                <a href="https://support.google.com/googleplay/android-developer/answer/6048248?hl=en">Google's website</a> regarding their Advertising ID.
              </li>
            </ul>
          </div>
          </li>
          <li>
            <p>
              <strong>Note</strong>: if you are using Android Studio 3.0+, you'll need to disable AAPT 2.0. 
            </p>
          </li>
          <li>
            To do this, you'll need to add the following to your gradle.properties:<br>
            android.enableAapt2=false
          </li>
        
      </ul>
    </div>
