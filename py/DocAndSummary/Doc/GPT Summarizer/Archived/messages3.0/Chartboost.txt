SDK Privacy Methods
Chartboost requires publishers to obtain consent from their users in order to process personal data and provide relevant ads. Apps under the
Google Play Designed for Families
policy
MUST
set the COPPA privacy flag to
true
. Review our
COPPA FAQs
for more information on behavior targeting.
The
addDataUseConsent
is the new public API usage to set consent values. This new API provides user consent data for privacy laws currently in existence or future laws. Replaces
CBPIDataUseConsent
method.
