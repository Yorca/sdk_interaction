# Get Started

## Prerequisites

minSdkVersion 19 or higher

## Import the Bigo Ads SDK

  1. In your project-level `build.gradle` file, include [Maven central repository](https://search.maven.org/artifact) in both your `buildscript` and `allprojects` sections:
    
        buildscript {
        repositories {
            ...
            mavenCentral()
        }
    }
    
    allprojects {
        repositories {
            ...
            mavenCentral()
        }
    }
    

  2. Add the dependencies for the Bigo Ads SDK to your module's app-level Gradle file, which is usually `app/build.gradle`:
    
        dependencies {
        ...
        implementation 'com.bigossp:bigo-ads:4.9.1'
    }
    

  3. Set Specific Domain ClearText. BigoAds SDK has some features to lower ad latency, which could serve ads faster. To enable these features, please follow below instruction and allow 127.0.0.1 cleartext.  
Create a file `res/xml/network_security_config.xml` in the following path with
the following content:

    
        <?xml version="1.0" encoding="utf-8"?>
    <network-security-config>
        ...
        <domain-config cleartextTrafficPermitted="true">
        <domain includeSubdomains="true">127.0.0.1</domain>
        </domain-config>
        ...
    </network-security-config>
    

Add _android:networkSecurityConfig="@xml/network_security_config"_ to
`AndroidManifest.xml`:

    
        <?xml version="1.0" encoding="utf-8"?>
    <manifest ...>
        <uses-permission android:name="android.permission.INTERNET" />
        <application
            ...
            android:networkSecurityConfig="@xml/network_security_config">
            ...
        </application>
    </manifest>
    

## Initialize the Bigo Ads SDK

Before sending any ad requests, you need to inititalize the Bigo Ads SDK,
please do initialization like below: The first step is to construct an
`AdConfig` object by its builder:

    
    
    AdConfig config = new AdConfig.Builder()
            .setAppId("<your-app-Id>")
            .setDebug(BuildConfig.DEBUG)
            .setChannel("<your-app-channel>")
            .setAge("<your-app-user-age>")
            .setGender(AdConfig.GENDER_MALE)
            .setActivatedTime("<your-app-activated-timestamp>")
            .build();
    

AdConfig.Builder Method| Description| -  
---|---|---  
setAppId| Set up your App Id which could be found from the [BigoAds
Platform](https://www.bigossp.com/).| Required  
setDebug| Set debug mode. If set true, there will be more log output to help
you troubleshooting during the integration. The default value is false. **Make
sure to set false before you launch your app into public officially**.|
Optional  
setChannel| Set your app's distribution channel. This will help us to optimize
the efficiency of advertising monetization by channel.| Optional  
setAge| Set user's age.| Optional  
setGender| Set user's gender. 1:femaleï¼2:male| Optional  
setActivatedTime| Set app's activated timestamp.| Optional  
  
Next, call the `BigoAdSdk.initialize()` method which need to be done only
once, and ideally at the time when app launchs. You can pass in a
`BigoAdSdk.InitListener` instance to receive the callback of the completion of
initialization. Here's an example how to do the initialization when an
`Application` create:

    
    
    ...
    import sg.bigo.ads.BigoAdSdk;
    import sg.bigo.ads.api.AdConfig;
    
    public class AdApplication extends Application {
        
        @Override
        public void onCreate() {
            ...
            AdConfig config = new AdConfig.Builder()
                    .setAppId("<your-app-id>")
                    .setDebug(BuildConfig.DEBUG)
                    .setChannel("<your-app-channel>")
                    .setAge("<your-app-user-age>")
                    .setGender(AdConfig.GENDER_MALE)
                    .setActivatedTime("<your-app-activated-timestamp>")
                    .build();
            BigoAdSdk.initialize(this, config, new BigoAdSdk.InitListener() {
                @Override
                public void onInitialized() {
                    // You can request ads now!
                }
            });
        }
    }
    

# Ad Formats

## Banner Ads

Banner ads occupy a spot within an app's layout(bottom etc.). They display on
screen while users are interacting with the app, and can refresh automatically
after a certain period of time.

### Load an ad

Before requesting banner ads, please make sure that the Bigo Ads SDK has been
[initialized](https://www.bigossp.com/guide/sdk/android/document#initialize-
the-bigo-ads-sdk).

To request an banner ad, you need to declare a `BannerAd` object first:

    
    
    BannerAd mBannerAd;
    

Then construct a `BannerAdRequest` instance and pass in the Slot Id and
expected [Banner
sizes](https://www.bigossp.com/guide/sdk/android/document#banner-sizes).

    
    
    BannerAdRequest bannerAdRequest = new BannerAdRequest.Builder()
                    .withSlotId("<your-slot-id>")
                    .withAdSizes(AdSize.BANNER)
                    .withAge("<your-app-user-age>")
                    .withGender(AdConfig.GENDER_MALE)
                    .withActivatedTime("<your-app-activated-timestamp>")
                    .build();
    

BannerAdRequest.Builder Method| Decription  
---|---  
withSlotId| Pass in the Slot Id that referred to this ad (you can find it on
[Bigo Ads platform](https://www.bigossp.com/)).  
withAdSizes| Pass in the expected [Banner
sizes](https://www.bigossp.com/guide/sdk/android/document#banner-sizes). It's
acceptable to pass in multiple standard sizes specified by Bigo Ads at the
same time.  
withAge| Pass user's age.  
withGender| Pass user's gender. 1:femaleï¼2:male  
withActivatedTime| Pass app's activated timestamp.  
  
Next, construct a `BannerAdLoader` instance and pass in the `AdLoadListener`
to receive callbacks from the ad request. Now, call `loadAd()` method to start
an ad request:

    
    
    BannerAdLoader bannerAdLoader = new BannerAdLoader.Builder().
            withAdLoadListener(new AdLoadListener<BannerAd>() {
                @Override
                public void onError(@NonNull AdError error) {
                    // There's something wrong during ad loading
                }
    
                @Override
                public void onAdLoaded(@NonNull BannerAd ad) {
                    mBannerAd = ad;
                }
            }).build();
    
    bannerAdLoader.loadAd(bannerAdRequest);
    

AdLoadListener<BannerAd> Callback| Description  
---|---  
onError(AdError error)| This callback will be triggered when the ad request
fails. Please use the `AdError.getCode()` and `AdError.getMessage()` Method to
check the error code and message. You can find more details in [Error
codes](https://www.bigossp.com/guide/sdk/android/document#ad-request-error-
codes).  
onAdLoaded(BannerAd ad)| This callback will be triggered if the ad request
succeeds, meanwhile, an `BannerAd` instance will be returned.  
  
Here's an example that shows how to load an banner ad in the `onCreate()`
method of an Activity:

    
    
    ...
    import sg.bigo.ads.api.AdError;
    import sg.bigo.ads.api.AdLoadListener;
    import sg.bigo.ads.api.AdSize;
    import sg.bigo.ads.api.BannerAd;
    import sg.bigo.ads.api.BannerAdLoader;
    import sg.bigo.ads.api.BannerAdRequest;
    
    public class MainActivity extends Activity {
    
        BannerAd mBannerAd;
    
        @Override
        protected void onCreate(@Nullable Bundle savedInstanceState) {
            ...
            BannerAdRequest bannerAdRequest = new BannerAdRequest.Builder()
                    .withSlotId("<your-slot-id>")
                    .withAdSizes(AdSize.BANNER)
                    .build();
            BannerAdLoader bannerAdLoader = new BannerAdLoader.Builder().
                    withAdLoadListener(new AdLoadListener<BannerAd>() {
                        @Override
                        public void onError(@NonNull AdError error) {
                            // There's something wrong during ad loading
                        }
    
                        @Override
                        public void onAdLoaded(@NonNull BannerAd ad) {
                            mBannerAd = ad;
                        }
                    }).build();
            bannerAdLoader.loadAd(bannerAdRequest);
        }
    }
    

### Show banner ad

You can register the ad events listener through the
`setAdInteractionListener()` method once ad request succeeds:

    
    
    mBannerAd.setAdInteractionListener(new AdInteractionListener() {
        @Override
        public void onAdError(@NonNull AdError error) {
            // There's something wrong when using this ad.
        }
    
        @Override
        public void onAdImpression() {
            // When the ad appears on the screen.
        }
    
        @Override
        public void onAdClicked() {
            // When the user clicks on the ad.
        }
    
        @Override
        public void onAdOpened() {
    
        }
    
        @Override
        public void onAdClosed() {
    
        }
    });
    

AdInteractionListener Callback| Description  
---|---  
onAdError| Indicates that some exceptions occurred during using the ad.  
onAdImpression| Indicates that the ad has been displayed successfully on the
device screen.  
onAdClicked| Indicates that the ad was clicked by the user.  
onAdOpened| (Banner ads will not trigger this callback.)  
onAdClosed| (Banner ads will not trigger this callback.)  
  
Then, call the `adView()` method to get the banner ad view and add it to the
current window:

    
    
    adViewContainer.addView(mBannerAd.adView());
    

> Please use the `BannerAd.isExpired()` method to identify whether the ad has
> expired (the validity period of the ad is usually 60 minutes) before it is
> displayed. If an ad has expired, it should be discarded and destroyed, and
> then request a new one.

### Destroy an ad

After the ad does not need to be displayed any more, you should destroy it:

    
    
    adViewContainer.removeAllViews();
    mBannerAd.destroy();

## Interstitial Ads

Interstitial ads are full-screen ads. They're typically displayed at natural
transition points in the flow of using an app. When an interstitial ad
displays, the user could choose to either tap on the ad to access to its
landing page or close it and return to the app.

### Load an ad

Before requesting interstitial ads, please make sure that the Bigo Ads SDK has
been
[initialized](https://www.bigossp.com/guide/sdk/android/document#initialize-
the-bigo-ads-sdk).

To request an interstitial ad, you need to declare a `InterstitialAd` object
first:

    
    
    InterstitialAd mInterstitialAd;
    

And then construct a `InterstitialAdRequest` instance and pass in the Slot Id:

    
    
    InterstitialAdRequest interstitialAdRequest = new InterstitialAdRequest.Builder()
            .withSlotId("<your-slot-id>")
            .withAge("<your-app-user-age>")
            .withGender(AdConfig.GENDER_MALE)
            .withActivatedTime("<your-app-activated-timestamp>")
            .build();
    

InterstitialAdRequest.Builder Method| Decription  
---|---  
withSlotId| Pass in the Slot Id that referred to this ad (you can find it on
[Bigo Ads platform](https://www.bigossp.com/)).  
withAge| Pass user's age.  
withGender| Pass user's gender. 1:femaleï¼2:male  
withActivatedTime| Pass app's activated timestamp.  
  
Next, construct an `InterstitialAdLoader` instance and pass in the
`AdLoadListener` to receive callbacks from the ad request. Now, call
`loadAd()` method to start a ad request:

    
    
    InterstitialAdLoader interstitialAdLoader = new InterstitialAdLoader.Builder().
            withAdLoadListener(new AdLoadListener<InterstitialAd>() {
                @Override
                public void onError(@NonNull AdError error) {
                    // There's something wrong during ad loading
                }
    
                @Override
                public void onAdLoaded(@NonNull InterstitialAd ad) {
                    mInterstitialAd = ad;
                }
            }).build();
    
    interstitialAdLoader.loadAd(interstitialAdRequest);
    

AdLoadListener<InterstitialAd> Callback| Description  
---|---  
onError(AdError error)| This callback will be triggered when the ad request
fails. Please use the `AdError.getCode()` and `AdError.getMessage()` Method to
check the error code and message. You can find more details in [Error
codes](https://www.bigossp.com/guide/sdk/android/document#ad-request-error-
codes).  
onAdLoaded(InterstitialAd ad)| This callback will be triggered if the ad
request succeeds, meanwhie,an `InterstitialAd` instance will be returned.  
  
Here's an example that shows how to load an interstitial ad in the
`onCreate()` method of an Activity:

    
    
    ...
    import sg.bigo.ads.api.AdError;
    import sg.bigo.ads.api.AdLoadListener;
    import sg.bigo.ads.api.InterstitialAd;
    import sg.bigo.ads.api.InterstitialAdLoader;
    import sg.bigo.ads.api.InterstitialAdRequest;
    
    public class MainActivity extends Activity {
    
        InterstitialAd mInterstitialAd;
    
        @Override
        protected void onCreate(@Nullable Bundle savedInstanceState) {
            ...
            InterstitialAdRequest interstitialAdRequest = new InterstitialAdRequest.Builder()
                    .withSlotId("<your-slot-id>")
                    .build();
            InterstitialAdLoader interstitialAdLoader = new InterstitialAdLoader.Builder().
                    withAdLoadListener(new AdLoadListener<InterstitialAd>() {
                        @Override
                        public void onError(@NonNull AdError error) {
                            // There's something wrong during ad loading
                        }
    
                        @Override
                        public void onAdLoaded(@NonNull InterstitialAd ad) {
                            mInterstitialAd = ad;
                        }
                    }).build();
            interstitialAdLoader.loadAd(interstitialAdRequest);
        }
    }

styles, half-screen and full-screen in vertical and horizontal direction are

        protected void onResume() {
            super.onResume();
            int uiOptions = View.SYSTEM_UI_FLAG_HIDE_NAVIGATION | View.SYSTEM_UI_FLAG_IMMERSIVE_STICKY;
            getWindow().getDecorView().setSystemUiVisibility(uiOptions);
        }
    
        @Override
        protected void onDestroy() {
            super.onDestroy();
            if (mSplashAd != null) mSplashAd.destroy();
        }
    }
    

Please hold the SplashActivity running when users press the back button during
the splash ad displaying. We strongly recommended that whether users could
skip the SplashActivity is determined by `SplashAd.isSkippable()` method (like
the code example above).

> More tips:
>
>   * Each Slot Id can only cache a splash ad at the same time. Repeated
> requests at the same time will only return the ad of first success.
>   * In general, one splash ad shall be shown once. Please use the
> `SplashAd.isExpired()` method to identify whether the ad has expired (the
> validity period of the ad is usually more than 60 minutes) before it is
> displayed. If an ad has expired, it should be discarded and destroyed, and
> then request a new one.
>

### Destroy an ad

After the ad is closed, you should destroy it when it is no longer used:

    
    
    mSplashAd.destroy();

### GDPR

This section is provided for compliance with the European Union's [General
Data Protection Regulation (GDPR)](https://gdpr.eu/).

In order to pass GDPR consent from your users, you should make use of the
following API to pass a consent flag to the Bigo Ads SDK:

    
    
    import sg.bigo.ads.BigoAdSdk;
    import sg.bigo.ads.ConsentOptions;
    ...
    
    BigoAdSdk.setUserConsent(context, ConsentOptions.GDPR, true);
    

> A value of "**true** " implies the user has given consent to store and
> process personal information and a value of "**false** " means the user has
> declined consent.

## Pass Mediation SDK Info

More and more publishers are going to integrate BigoAds SDK, while they might
using different mediation. We strongly suggest you, as mediation platform,
pass mediation info to BigoAds SDK when constructing an ad request, which will
give a convenience to us to locate the our publishers' problem faster and help
us optimize revenue from various mediation platform

Parameters| Description| -  
---|---|---  
mediationName| The name of mediation| Required  
mediationVersion| Mediation SDK's version| Required  
adapterVersion| Bigo adapter version| Required  
  
Below are samples when constructing an ad request:

Creat `AdLoader` instance and use `withExt()` interface pass mediation info
when load ad.

    
    
    JSONObject extJSON = new JSONObject();
    extJSON.putOpt("mediationName", "<your-mediation-name>"); // admobãmeta etc.
    extJSON.putOpt("mediationVersion", "<your-mediation-version>"); // 12.1.0
    extJSON.putOpt("adapterVersion", "<your-adapter-version>"); // 12.1.0.0
    String extString = extJSON.toString();
    
    // BannerAd
    BannerAdLoader bannerAdLoader = new BannerAdLoader.Builder()
            .withAdLoadListener(listener)
            .withExt(extString)
            .build();
    bannerAdLoader.loadAd(bannerAdRequest);
    
    
    // NativeAd
    NativeAdLoader nativeAdLoader = new NativeAdLoader.Builder()
            .withAdLoadListener(listener)
            .withExt(extString)
            .build();
    nativeAdLoader.loadAd(nativeAdRequest);
    
    
    // InterstitialAd
    InterstitialAdLoader interstitialAdLoader = new InterstitialAdLoader.Builder()
            .withAdLoadListener(listener)
            .withExt(extString)
            .build();
    interstitialAdLoader.loadAd(interstitialAdRequest);
    
    
    // RewardVideoAd
    RewardVideoAdLoader rewardVideoAdAdLoader = new RewardVideoAdLoader.Builder()

            .withExt(extString)
