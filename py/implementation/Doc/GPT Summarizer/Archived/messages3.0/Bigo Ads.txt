<h2 id="prerequisites">Prerequisites</h2>
<p>minSdkVersion 19 or higher</p>
<h2 id="import-the-bigo-ads-sdk">Import the Bigo Ads SDK</h2>
<ol>
<li>
<p>In your project-level <code>build.gradle</code> file, include <a href="https://search.maven.org/artifact">Maven central repository</a> in both your <code>buildscript</code> and <code>allprojects</code> sections:</p>
<pre><code class="hljs language-groovy">buildscript {
    repositories {
        ...
        mavenCentral()
    }
}

allprojects {
    repositories {
        ...
        mavenCentral()
    }
}
</code></pre>
</li>
<li>
<p>Add the dependencies for the Bigo Ads SDK to your module's app-level Gradle file, which is usually <code>app/build.gradle</code>:</p>
<pre><code class="hljs language-groovy">dependencies {
    ...
    implementation 'com.bigossp:bigo-ads:4.9.1'
}
</code></pre>
</li>
<li>
<p>Set Specific Domain ClearText. BigoAds SDK has some features to lower ad latency, which could serve ads faster. To enable these features, please follow below instruction and allow 127.0.0.1 cleartext.<br>Create a file <code>res/xml/network_security_config.xml</code> in the following path with the following content:</p>
<pre><code class="hljs language-xml"><span class="hljs-meta">&lt;?xml version=<span class="hljs-string">"1.0"</span> encoding=<span class="hljs-string">"utf-8"</span>?&gt;</span>
<span class="hljs-tag">&lt;<span class="hljs-name">network-security-config</span>&gt;</span>
    ...
    <span class="hljs-tag">&lt;<span class="hljs-name">domain-config</span> <span class="hljs-attr">cleartextTrafficPermitted</span>=<span class="hljs-string">"true"</span>&gt;</span>
    <span class="hljs-tag">&lt;<span class="hljs-name">domain</span> <span class="hljs-attr">includeSubdomains</span>=<span class="hljs-string">"true"</span>&gt;</span>127.0.0.1<span class="hljs-tag">&lt;/<span class="hljs-name">domain</span>&gt;</span>
    <span class="hljs-tag">&lt;/<span class="hljs-name">domain-config</span>&gt;</span>
    ...
<span class="hljs-tag">&lt;/<span class="hljs-name">network-security-config</span>&gt;</span>
</code></pre>
<p>Add <em>android:networkSecurityConfig="@xml/network_security_config"</em> to <code>AndroidManifest.xml</code>:</p>
<pre><code class="hljs language-xml"><span class="hljs-meta">&lt;?xml version=<span class="hljs-string">"1.0"</span> encoding=<span class="hljs-string">"utf-8"</span>?&gt;</span>
<span class="hljs-tag">&lt;<span class="hljs-name">manifest</span> <span class="hljs-attr">...</span>&gt;</span>
    <span class="hljs-tag">&lt;<span class="hljs-name">uses-permission</span> <span class="hljs-attr">android:name</span>=<span class="hljs-string">"android.permission.INTERNET"</span> /&gt;</span>
    <span class="hljs-tag">&lt;<span class="hljs-name">application</span>
        <span class="hljs-attr">...</span>
        <span class="hljs-attr">android:networkSecurityConfig</span>=<span class="hljs-string">"@xml/network_security_config"</span>&gt;</span>
        ...
    <span class="hljs-tag">&lt;/<span class="hljs-name">application</span>&gt;</span>
<span class="hljs-tag">&lt;/<span class="hljs-name">manifest</span>&gt;</span>
</code></pre>
</li>
</ol>

<h2 id="initialize-the-bigo-ads-sdk">Initialize the Bigo Ads SDK</h2>
<p>Before sending any ad requests, you need to inititalize the Bigo Ads SDK, please do initialization like below:
The first step is to construct an <code>AdConfig</code> object by its builder:</p>
<pre><code class="hljs language-java"><span class="hljs-type">AdConfig</span> <span class="hljs-variable">config</span> <span class="hljs-operator">=</span> <span class="hljs-keyword">new</span> <span class="hljs-title class_">AdConfig</span>.Builder()
        .setAppId(<span class="hljs-string">"&lt;your-app-Id&gt;"</span>)
        .setDebug(BuildConfig.DEBUG)
        .setChannel(<span class="hljs-string">"&lt;your-app-channel&gt;"</span>)
        .setAge(<span class="hljs-string">"&lt;your-app-user-age&gt;"</span>)
        .setGender(AdConfig.GENDER_MALE)
        .setActivatedTime(<span class="hljs-string">"&lt;your-app-activated-timestamp&gt;"</span>)
        .build();
</code></pre>

<h1 id="ad-formats">Ad Formats</h1>
<h2 id="banner-ads">Banner Ads</h2>
<p>Banner ads occupy a spot within an app's layout(bottom etc.). They display on screen while users are interacting with the app, and can refresh automatically after a certain period of time.</p>
<h3 id="load-an-ad">Load an ad</h3>
<p>Before requesting banner ads, please make sure that the Bigo Ads SDK has been <a href="https://www.bigossp.com/guide/sdk/android/document#initialize-the-bigo-ads-sdk">initialized</a>.</p>
<p>To request an banner ad, you need to declare a <code>BannerAd</code> object first:</p>
<pre><code class="hljs language-java">BannerAd mBannerAd;
</code></pre>
<p>Then construct a <code>BannerAdRequest</code> instance and pass in the Slot Id and expected <a href="https://www.bigossp.com/guide/sdk/android/document#banner-sizes">Banner sizes</a>.</p>
<pre><code class="hljs language-java"><span class="hljs-type">BannerAdRequest</span> <span class="hljs-variable">bannerAdRequest</span> <span class="hljs-operator">=</span> <span class="hljs-keyword">new</span> <span class="hljs-title class_">BannerAdRequest</span>.Builder()
                .withSlotId(<span class="hljs-string">"&lt;your-slot-id&gt;"</span>)
                .withAdSizes(AdSize.BANNER)
                .withAge(<span class="hljs-string">"&lt;your-app-user-age&gt;"</span>)
                .withGender(AdConfig.GENDER_MALE)
                .withActivatedTime(<span class="hljs-string">"&lt;your-app-activated-timestamp&gt;"</span>)
                .build();
</code></pre>





























<table><thead><tr><th>BannerAdRequest.Builder Method</th><th>Decription</th></tr></thead><tbody><tr><td>withSlotId</td><td>Pass in the Slot Id that referred to this ad (you can find it on <a href="https://www.bigossp.com/">Bigo Ads platform</a>).</td></tr><tr><td>withAdSizes</td><td>Pass in the expected <a href="https://www.bigossp.com/guide/sdk/android/document#banner-sizes">Banner sizes</a>. It's acceptable to pass in multiple standard sizes specified by Bigo Ads at the same time.</td></tr><tr><td>withAge</td><td>Pass user's age.</td></tr><tr><td>withGender</td><td>Pass user's gender. 1:femaleï¼2:male</td></tr><tr><td>withActivatedTime</td><td>Pass app's activated timestamp.</td></tr></tbody></table>
<p>Next, construct a <code>BannerAdLoader</code> instance and pass in the <code>AdLoadListener</code> to receive callbacks from the ad request. Now, call <code>loadAd()</code> method to start an ad request:</p>
<pre><code class="hljs language-java"><span class="hljs-type">BannerAdLoader</span> <span class="hljs-variable">bannerAdLoader</span> <span class="hljs-operator">=</span> <span class="hljs-keyword">new</span> <span class="hljs-title class_">BannerAdLoader</span>.Builder().
        withAdLoadListener(<span class="hljs-keyword">new</span> <span class="hljs-title class_">AdLoadListener</span>&lt;BannerAd&gt;() {
            <span class="hljs-meta">@Override</span>
            <span class="hljs-keyword">public</span> <span class="hljs-keyword">void</span> <span class="hljs-title function_">onError</span><span class="hljs-params">(<span class="hljs-meta">@NonNull</span> AdError error)</span> {
                <span class="hljs-comment">// There's something wrong during ad loading</span>
            }

            <span class="hljs-meta">@Override</span>
            <span class="hljs-keyword">public</span> <span class="hljs-keyword">void</span> <span class="hljs-title function_">onAdLoaded</span><span class="hljs-params">(<span class="hljs-meta">@NonNull</span> BannerAd ad)</span> {
                mBannerAd = ad;
            }
        }).build();

bannerAdLoader.loadAd(bannerAdRequest);
</code></pre>

















<table><thead><tr><th>AdLoadListener&lt;BannerAd&gt; Callback</th><th>Description</th></tr></thead><tbody><tr><td>onError(AdError error)</td><td>This callback will be triggered when the ad request fails. You can find more details in <a href="https://www.bigossp.com/guide/sdk/android/document#ad-request-error-codes">Error codes</a>.</td></tr><tr><td>onAdLoaded(BannerAd ad)</td><td>This callback will be triggered if the ad request succeeds, meanwhile, an <code>BannerAd</code> instance will be returned.</td></tr></tbody></table>

<h2 id="interstitial-ads">Interstitial Ads</h2>
<p>Interstitial ads are full-screen ads. They're typically displayed at natural transition points in the flow of using an app. When an interstitial ad displays, the user could choose to either tap on the ad to access to its landing page or close it and return to the app.</p>
<h3 id="load-an-ad-2">Load an ad</h3>
<p>Before requesting interstitial ads, please make sure that the Bigo Ads SDK has been <a href="https://www.bigossp.com/guide/sdk/android/document#initialize-the-bigo-ads-sdk">initialized</a>.</p>
<p>To request an interstitial ad, you need to declare a <code>InterstitialAd</code> object first:</p>
<pre><code class="hljs language-java">InterstitialAd mInterstitialAd;
</code></pre>
<p>And then construct a <code>InterstitialAdRequest</code> instance and pass in the Slot Id:</p>
<pre><code class="hljs language-java"><span class="hljs-type">InterstitialAdRequest</span> <span class="hljs-variable">interstitialAdRequest</span> <span class="hljs-operator">=</span> <span class="hljs-keyword">new</span> <span class="hljs-title class_">InterstitialAdRequest</span>.Builder()

        .withActivatedTime(<span class="hljs-string">"&lt;your-app-activated-timestamp&gt;"</span>)
        .build();
</code></pre>

Provoke <code>SplashAd.show()</code> method and display a splash ad which is simple. We strongly recommend you to use this method.</td></tr><tr><td><code>showInAdContainer(ViewGroup)</code></td><td>This method aims for publishers who have customized needs to display a splash ad. Publishers who use this method need construct a ViewGroup,such as FrameLayout or RelativeLayout,then SDK will add splash ad view into this group. This method is more complicated than <code>show()</code> method.</td></tr></tbody></table>
<p>Below will introduce the two methods</p>
<h4 id="1-show-method">1. <code>show()</code> method</h4>
<p>When a splash ad fills, provoke <code>show()</code> method and display the ad</p>
<pre><code class="hljs language-java">mSplashAd.show();
</code></pre>
<blockquote>
<ul>
<li>Each Slot Id can only cache a splash ad at the same time. Repeated requests at the same time will only return the ad of first success.</li>
<li>In general, one splash ad shall be shown once. Please use the <code>SplashAd.isExpired()</code> method to identify whether the ad has expired (the validity period of the ad is usually more than 60 minutes) before it is displayed. If an ad has expired, it should be discarded and destroyed, and then request a new one.</li>
</ul>
</blockquote>
<h4 id="2-showinadcontainerviewgroup-method">2. <code>showInAdContainer(ViewGroup)</code> method</h4>
<p>Before displaying splash ads, you shall register ad events listener through the <code>setAdInteractionListener()</code> method once an ad request succeeds.</p>
<pre><code class="hljs language-java">mSplashAd.setAdInteractionListener(<span class="hljs-keyword">new</span> <span class="hljs-title class_">SplashAdInteractionListener</span>() { ... });
</code></pre>

































<table><thead><tr><th>SplashAdInteractionListener Callback</th><th>Description</th></tr></thead><tbody><tr><td>onAdError</td><td>Indicates that some exceptions occurred during using the ad.</td></tr><tr><td>onAdImpression</td><td>Indicates that the ad has been displayed successfully on the device screen.</td></tr><tr><td>onAdClicked</td><td>Indicates that the ad is clicked by the user.</td></tr><tr><td>onAdSkipped</td><td>Indicates the skip button is clicked, and the splash ad shall be dismissed immediately.</td></tr><tr><td>onAdOpened</td><td>(Splash ads will not trigger this callback.)</td></tr><tr><td>onAdClosed</td><td>(Splash ads will not trigger this callback.)</td></tr></tbody></table>
<p>Next, call the <code>showInAdContainer()</code> method and pass in <strong>container view</strong> which is designed for displaying splash ad view</p>
<pre><code class="hljs language-java">mSplashAd.showInAdContainer(containerView);
</code></pre>
<p>To ensure best user experience, <strong>please pass in full screen container view</strong>. The ad view provided by Bigo Ads SDK includes some elements which are significant for ad integration and display, please fully acknowledge these and follow the guidance as following specifications:</p>
<img src="https://static-web.likeevideo.com/as/common-static/big-data/bigossp/assets/images/splash_3_en.png" width="360">

































<table><thead><tr><th>Attribute</th><th>Description</th></tr></thead><tbody><tr><td>Container view</td><td>Hold splash ad view and please pass in full screen size container view.</td></tr><tr><td>Splash ad view</td><td>Provided by Bigo Ads SDK which contain ad creatives and some controllers.</td></tr><tr><td>Splash ad duration</td><td>The maximum ad displaying duration can be revised on Bigo Ads platform. The countdown will automatically pause when splash ad is invisibale (such as opening the landing page).</td></tr><tr><td>Skip button</td><td>Skip button can be set when it is available to click. You can set an appropriate time for displaying skippable button on Bigo Ads platform. When skippable button is clicked, <code>onAdSkipped</code> will be triggered, and you shall dismiss splash ad.</td></tr><tr><td>Your app logo</td><td>When you choose to display half-screen style,your app logo shall be provided as a must, otherwise the area of ad bottom is blank which may affect user experience.</td></tr><tr><td>Your app name</td><td>When you choose to display half-screen style,your app name shall be provided as a must, otherwise the area of ad bottom is blank which may affect user experience.</td></tr></tbody></table>
