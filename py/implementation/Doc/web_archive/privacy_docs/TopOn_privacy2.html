Google Data Security Guidelines

According to Google's data security requirements, developers need to disclose what data is collected by their apps and all SDKs integrated into their apps.

TopOn lists that the data collected by the TopOn SDK can be used to answer Google's data security questionnaire.

Tips:

1. This information is only used to answer Google's data security questionnaire , for specific TopOn Privacy Compliance Guidelines, please read "TopOn Privacy Compliance Guidelines"
