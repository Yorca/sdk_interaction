## Publisher first-party ID, formerly known as same app key

**Note:** Same app key has been renamed to [Publisher first-party
ID](//support.google.com/admanager/answer/11402075) . The same app key API
changed to reflect Publisher first-party ID in version 22.6.0. This change
doesn't impact existing activation of same app key for Google Mobile Ads SDK
versions 21.4.0 to 22.5.0. All applicable SDK versions process the identifier
seamlessly.

**Prerequisites: Google Mobile Ads SDK 21.4.0 or higher**

The Google Mobile Ads SDK introduced [Publisher first-party
ID](//support.google.com/admanager/answer/11402075), formerly known as same
app key to help you deliver more relevant and personalized ads by using data
collected from your apps.

Publisher first-party ID is enabled by default, but you can disable it using
the following method.

### Kotlin

    
    
    // Disables Publisher first-party ID, formerly known as same app key.
    MobileAds.putPublisherFirstPartyIdEnabled(false)
    

### Java

    
    
    // Disables Publisher first-party ID, formerly known as same app key.
    MobileAds.putPublisherFirstPartyIdEnabled(false);
