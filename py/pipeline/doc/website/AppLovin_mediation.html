You set the compileSdkVersion of your app in build.gradle. Google Mobile Ads SDK versions 20.5.0 and newer require that you set compileSdkVersion to 31. Google Mobile Ads SDK version 20.4.0.1 is the most recent version that still supports setting compileSdkVersion to 30.
