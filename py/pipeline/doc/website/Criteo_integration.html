Standalone SDK

This guide explains how to integrate Criteo Direct Bidding for App solution to your Android app as a Standalone Ads SDK.

Prerequisites

  • Criteo Publisher SDK

SDK Initialization

Initialize Criteo SDK in your Application class by using Criteo.Builder() method. This needs to be done only once. Criteo.Builder() method takes 2 parameters:

Parameter Type Description
application Application Application Object
criteoPublisherId String Your Criteo Publisher ID.
Contact your Criteo representative to get your Criteo Publisher ID.

Use adUnits() method on the builder and pass List<AdUnit> object to initialize all ad units that Criteo will monetize.

public class MyApplication extends Application {

    @Override
    protected void onCreate() {
        super.onCreate();

        String criteoPublisherId = "B-000000";

        // Define Criteo ad units
        BannerAdUnit bannerAdUnit = 
            new BannerAdUnit("samplebanneradunitid", new AdSize(320, 50));
        InterstitialAdUnit interstitialAdUnit = 
            new InterstitialAdUnit("sampleinterstitialadunitid");
        NativeAdUnit nativeAdUnit =
            new NativeAdUnit("samplenativeadunitid");

        List<AdUnit> adUnits = new ArrayList<>();
        adUnits.add(bannerAdUnit);
        adUnits.add(interstitialAdUnit);
        adUnits.add(nativeAdUnit);

        // Initialize Criteo SDK
        try {
            new Criteo.Builder(this, criteoPublisherId)
                      .adUnits(adUnits)
                      .debugLogsEnabled(true)
                      .init();
        } catch (CriteoInitException e) {

        }
    }

}

class MyApplication : Application() {

    override fun onCreate() {
        super.onCreate()

        val criteoPublisherId = "B-000000"

        // Define Criteo ad units
        val bannerAdUnit = BannerAdUnit("samplebanneradunitid", AdSize(320, 50))
        val interstitialAdUnit = InterstitialAdUnit("sampleinterstitialadunitid")
        val nativeAdUnit = NativeAdUnit("samplenativeadunitid")
        val adUnits = listOf(bannerAdUnit, interstitialAdUnit, nativeAdUnit)

        // Initialize Criteo SDK
        try {
            Criteo.Builder(this, criteoPublisherId)
                .adUnits(adUnits)
                .debugLogsEnabled(true)
                .init()
        } catch (e: CriteoInitException) {

        }
    }
}

Banner

Displaying Banner

Add CriteoBannerView into your XML layout, with the following attributes:

Parameter Type Description
app:criteoAdUnitId String Your Criteo banner Ad Unit ID
app:criteoAdUnitHeight Integer Banner height
app:criteoAdUnitWidth Integer Banner width 
<com.criteo.publisher.CriteoBannerView
    android:id="@+id/criteoBannerView"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    app:criteoAdUnitId="samplebanneradunitid"
    app:criteoAdUnitWidth="320"
    app:criteoAdUnitHeight="50" />

Then, call loadAd() in your code to display Criteo banner.

CriteoBannerView criteoBannerView = findViewById(R.id.criteoBannerView);
criteoBannerView.loadAd();

criteoBannerView.loadAd()


Alternatively, create a CriteoBannerView object programatically, call loadAd() method, and add it as a subview in your layout.

// Initialize bannerView with banner ad unit.
CriteoBannerView criteoBannerView = new CriteoBannerView(context, bannerAdUnit);

// Load the bannerView with ad.
criteoBannerView.loadAd();

// Assuming adLayout is a LinearLayout in your Activity where you'd like Criteo Banner to be displayed
LinearLayout adLayout = findViewById(R.id.adLayout);
adLayout.addView(criteoBannerView);

// Initialize bannerView with banner ad unit.
val criteoBannerView = CriteoBannerView(context, bannerAdUnit)

// Load the bannerView with ad.
criteoBannerView.loadAd()

// Assuming adLayout is a LinearLayout in your Activity where you'd like Criteo Banner to be displayed
adLayout.addView(criteoBannerView)

Destroying Banner View

Make sure to destroy CriteoBannerView object when your Activity is destroyed.

@Override
protected void onDestroy() {
    super.onDestroy();
    bannerView.destroy();
}

override fun onDestroy() {
    super.onDestroy()
    bannerView.destroy()
}

Setting Ad Listener

You can optionally add an Ad Listener to your CriteoBannerView object in order to handle callbacks when banner view has loaded, failed to load, or there's a click resulting in the user leaving the application, by calling setCriteoBannerAdListener() with a CriteoBannerAdListener object as parameter, before loading the ad.

bannerView.setCriteoBannerAdListener(new CriteoBannerAdListener() {
    @Override
    public void onAdReceived(CriteoBannerView criteoBannerView) {
        // called when Criteo Ad is received and ready to be displayed
    }

    @Override
    public void onAdFailedToReceive(CriteoErrorCode criteoErrorCode) {
        // called when Criteo returns no ad. The error description gives further details on the failure.
    }

    @Override
    public void onAdLeftApplication() {
        // called when clicking on Criteo ad result in user leaving your application
    }

    @Override
    public void onAdClicked() {
        // called when user clicks on Criteo ad
    }
});

bannerView.setCriteoBannerAdListener(object : CriteoBannerAdListener {
    override fun onAdReceived(criteoBannerView: CriteoBannerView) {
        // called when Criteo Ad is received and ready to be displayed
    }

    override fun onAdFailedToReceive(criteoErrorCode: CriteoErrorCode) {
        // called when Criteo returns no ad. The error description gives further details on the failure.
    }

    override fun onAdLeftApplication() {
        // called when clicking on Criteo ad result in user leaving your application
    }

    override fun onAdClicked() {
        // called when user clicks on Criteo ad
    }
})

Interstitial

Loading Interstitial Ads

You can request for Interstitial Ad by creating a CriteoInterstitial object for your Interstitial Ad Unit, and call loadAd(). This will prefetch an Interstitial Ad that you can display later in your app.

// Initialize interstitial with interstitial ad unit
CriteoInterstitial interstitial = new CriteoInterstitial(interstitialAdUnit);

// Load the interstitial with ad.
interstitial.loadAd();

// Initialize interstitial with interstitial ad unit
val interstitial = CriteoInterstitial(interstitialAdUnit)

// Load the interstitial with ad.
interstitial.loadAd()

Displaying Interstitial Ads

Display previously-loaded Interstitial ad by calling show() method. Make sure to always check whether the Interstitial ad has been loaded using isAdLoaded() before presenting Criteo Interstitial ad to the user.

if (interstitial.isAdLoaded()) {
    interstitial.show();
}

if (interstitial.isAdLoaded) {
    interstitial.show()
}

Setting Ad Listener

You can optionally add an Ad Listener to your CriteoInterstitial object in order to handle callbacks when Interstitial view has loaded, failed to load, opened, closed or there's a click resulting in the user leaving the application, by calling setCriteoInterstitialAdListener() with a CriteoInterstitialAdListener object as parameter, before loading the ad.

interstitial.setCriteoInterstitialAdListener(new CriteoInterstitialAdListener() {
    @Override
    public void onAdReceived(CriteoInterstitial criteoInterstitial) {
        // called when Criteo Ad is received and ready to be displayed.
        // at this point, CriteoInterstitial#isAdLoaded() always returns true and
        // you are safe to call CriteoInterstitial#show()
    }

    @Override
    public void onAdFailedToReceive(CriteoErrorCode criteoErrorCode) {
        // called when Criteo returns no ad. The error description gives further details on the failure.
    }

    @Override
    public void onAdClicked() {
        // called when user clicks on an opened Criteo Interstitial ad
    }

    @Override
    public void onAdOpened() {
        // called when Criteo Interstitial ad is opened and covering the screen
    }

    @Override
    public void onAdClosed() {
        // called when Criteo Interstitial ad is closed and user is back on the application
    }

    @Override
    public void onAdLeftApplication() {
        // called when clicking on Criteo ad result in user leaving your application
    }
});

interstitial.setCriteoInterstitialAdListener(object : CriteoInterstitialAdListener {
    override fun onAdReceived(criteoInterstitial: CriteoInterstitial) {
