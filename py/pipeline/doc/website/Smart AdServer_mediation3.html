Mediation Overview

Smart Display SDK can be used as a secondary SDK in mediation contexts, allowing to access Smart's unique demand and formats with other AdServer's SDKs.

  1. Open source adapters
  2. Integrate Smart Display SDK in another SDK

Open source adapters

Smart provides open-sourced adapters to be mediated by AppLovin MAX and Google Mobile Ads SDKs. Please follow the links for more informations:


Integrate Smart Display SDK in another SDK

Smart Display SDK can be integrated in every Ad network SDK offering Open Mediation features. If you are using a primary SDK that is not supported, 2 options:

  • Create your own adapters bridging from your primary SDK to Smart. Your primary Ad network most likely provide a documentation for this.
  • Contact your TAM at Smart to see if our tech team can create the adapters for you.
